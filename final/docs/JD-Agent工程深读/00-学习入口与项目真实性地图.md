# AGI-saber：对应 Agent 开发岗位的源码深读课

核验日期：2026-09-14。对象：当前工作区的 `AGI-saber-python/final`，不是某个已经发布且全量验收的生产版本。工作区有未提交改动，后续源码变化后应重新核对。本文档集只整理与解释实现，不代表本次又开发了这些功能。

## 先回答：这个项目到底是什么？

它是一个自建 Agent 执行与应用平台：前端接收用户问题，后端根据是否使用知识库和任务类型选择回答方式；需要执行动作时构建任务图，交给运行时调用工具或子代理；执行前装配上下文，执行后保存对话和处理记忆。外围还有文档库、猪场报表、质量评测、离线策略审批和受限的在线 RAG 实验。

面试时不要从“用了很多技术”开始，而要先讲一个闭环：

> 用户上传业务资料，提出问题或报告任务。系统检索证据、安排执行步骤、调用受控工具、记录执行轨迹，输出可追溯结果。我们再用分层评测定位检索、工具、记忆和流程失败，并把改动变成可比较、可审核的策略版本。

这是项目能力描述。你个人做了什么，要用自己实际完成和能解释的部分替换“我们”；AI 辅助生成的代码也需要你理解和验证，不能直接等同于独立设计经验。

## 哪些是真的，哪些需要附带条件？

“代码存在”“测试执行”“真实外部组件联调”“真实用户业务效果”是四种不同证据。下面是源码边界，不是实时健康检查结果。

| 能力 | 当前事实 | 面试时的准确说法 |
|---|---|---|
| 基础对话与 RAG | 有实际 HTTP 模型调用；也有本地/测试替身路径 | 模型与检索后端是否真实，要看本次配置和轨迹 |
| Agentic RAG | 知识库启用且已加载时，部分关键词触发固定四角色 DAG | 有编排式 Agentic RAG，不是无限自主研究 |
| 意图理解 | 路由条件、关键词、工具 matcher、业务解析共同实现 | 未看到独立训练的通用意图分类模型 |
| 原生 Function Calling | 当前 LLM 请求不发送 `tools/tool_choice` | 工具使用由 JSON 规划和本地执行器完成 |
| 会话隔离 | AgentRegistry 按用户缓存 Agent；ChatRequest 无会话 ID | 用户隔离存在，同一用户的多会话状态仍需独立设计 |
| 全局记忆 | 用户长期信息可跨请求保存 | 不是所有用户共享私有记忆，也不是自动全公司知识治理 |
| 上下文预算 | 槽位和总预算按字符长度裁剪 | 不是 tokenizer 精确预算，且不覆盖整个最终请求 |
| 图检索 | 可选 Neo4j 实体关系检索，并入 RRF | 不是社区摘要式 GraphRAG 完整系统 |
| 任务恢复 | 快照和状态恢复相关实现存在 | 不能据此承诺进程崩溃后副作用 exactly-once |
| 在线实验 | 控制面与只读 RAG 接入代码存在，默认关闭 | 未在本次阅读中验证真实流量显著收益 |
| 生产就绪 | 存在可演示业务和工程约束，也有明确缺口 | 可讲工程化项目，不宣称完成生产验收 |

## 先纠正最容易背错的八句话

1. “固定版 12/12，所以模型准确率 100%”——这些演示是预制回放输出，证明评测闭环，不证明模型质量。
2. “三路权重是 0.7/0.3 加权余弦”——代码用排名融合 RRF；语义和关键词默认各 1，图权重单独设置。
3. “写了 review_agent，就会自动修改不合格报告”——当前审查输出是意见；保存取写作结果，不做自动修订硬门禁。
4. “说不要保存就肯定不会写库”——当前强制报告 DAG 的路由关键词很宽，不能把自然语言否定当授权保护。
5. “数据库有快照就能任意断点续跑”——状态恢复不等于外部副作用可安全重放。
6. “消息队列保证记忆完全不丢”——抽取入口是进程内队列；持久化 outbox 保障的是已提交记忆的后续投影。
7. “readyz 返回 ok，依赖全正常”——当前 `/readyz` 是兼容性探针，直接返回 ok。
8. “Python 完全复刻 Go 的所有行为”——应限定冻结版本、已核对的契约和测试范围，不能把有限测试当全量形式化证明。

## 七次学习，而不是七天背稿

每次约 60～90 分钟。可以按自己的进度拆开。

1. 画一次对话和一次报告的两条时序，辨认路由和写入副作用。
2. 跟一个工具节点走成功、超时、取消路径；解释为什么重试会重复写。
3. 手算 RRF，给一个答错问题做阶段归因；读图谱实体写入。
4. 跟踪“旧偏好→更正→恢复→召回”，画事务与 outbox 时序。
5. 运行离线评测，亲自查看一个失败用例的输入、预期、实际和打分理由。
6. 读业务工具与安全边界；设计从单机到多实例最先要改的三件事。
7. 录制 10 分钟演示，抽答 80 题中 15 题；答不出就回源码，不补空话。

自测标准：能说出输入、输出、持久化位置、失败策略和证据边界，才算掌握模块。能背一个名词不算。
