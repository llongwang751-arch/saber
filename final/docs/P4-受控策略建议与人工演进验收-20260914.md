# P4 受控策略建议与人工演进验收

日期：2026-09-14

## 结论

项目已经实现“从失败证据生成下一轮实验假设”，但没有实现无人监管的自我修改或自动上线。系统只会基于一个已完成的离线 Run，以固定规则提出有界 RAG 参数建议；建议必须由不同人员审核，再显式物化为新的 P2 不可变策略版本，之后仍需重新跑 baseline/candidate、通过离线门禁和 P3 线上审批。

更准确的名称是“受控策略建议”或“人工审批的演进闭环”，不是“自主自进化”。

## 已落地能力

- 确定性规则：v1 仅根据检索失败、错误回答和过度拒答信号，建议 `top_k` 或 `no_answer_threshold`，参数范围与线上编译白名单一致。
- 证据快照：绑定源 Run、数据集版本、Case、逐例结果、Badcase、规则版本及多层 SHA-256 校验和；源 Run 若绑定了策略版本，还会冻结该策略清单及其校验和。
- 真实性标签：明确区分合成/Replay 假设与真实 Local/HTTP 离线假设；固定声明不能证明离线或线上提升。
- 不可变记录：证据、建议 Manifest、理由、限制和 checksum 创建后不可修改或删除。
- 双人审核：创建人不能接受自己的建议；接受和拒绝使用乐观并发代次及幂等键。
- 显式物化：只有 accepted 建议才能复制为新的 P2 StrategyVersion；物化不会创建 PromotionProposal、不会激活策略、不会创建线上 Deployment。
- 漂移防护：审核和物化前重新读取源 Run 与数据集证据；证据或持久化记录被修改时失败关闭。
- 租户与权限：生产模式下管理员才能创建/物化，审批人才能接受/拒绝；同租户协作、跨租户隔离。
- 追加审计：创建、审核、物化各自产生带操作者、请求摘要、幂等键和前后代次的审计事件；事件通过前序校验和串联，并把建议状态与当前审计链头绑定。
- 篡改失败关闭：审核、物化和读取详情前都会重验建议、源策略、证据校验和、状态快照与审计链；绕过 API 直接修改状态、删改事件或替换源策略时，不会继续物化。

## 生命周期

```text
completed evaluation run
        |
        v
proposed hypothesis --independent review--> accepted --explicit materialize--> P2 StrategyVersion
        |                                                                  |
        +------------------------reject------------------------------------+-> no runtime change

P2 StrategyVersion -> new offline baseline/candidate runs -> P2 approval -> P3 deployment/experiment
```

整条链路没有任何自动发布边。

## 验证结果

- 受控策略建议服务与攻击面专项：`python -m pytest tests/test_evaluation_evolution.py tests/test_evaluation_evidence_hardening.py -q`
- 前端中文化与交互契约：`python -m pytest tests/test_frontend_evolution_alignment.py -q`，并在 `web/` 执行 `npm run build`
- 全量回归：`python -m pytest tests -q`

当前工作区已执行专项与全量回归；静态文档不固化通过数。发布复核时必须在同一提交重跑上述命令、保留原始输出并注明跳过项；专项通过不能替代全量回归，也不能替代真实线上效果验证。

## 当前边界

- v1 是确定性规则驱动的有界参数建议，不是模型自主改代码、改提示词或直接学习线上行为。
- 摘要链用于检测数据库记录被删改或状态脱链，并不等同于外部不可篡改日志；生产仍应限制数据库写权限并把审计事件归档到独立系统。
- 当前资产只能证明状态机、证据绑定和失败关闭契约；没有真实线上结果时，不能宣称建议带来了业务提升。

## 面试中的准确说法

可以说：

> 我没有让 Agent 根据一次分数直接改线上配置，而是把 Badcase 到策略建议做成了证据绑定的状态机。v1 只生成两个有界 RAG 参数的实验假设，创建人不能自批；接受后也只是物化为不可变离线策略，仍要重新评测、人工审批和线上实验。这样能迭代，但不会把不可复现的“自进化”包装成自动收益。

不要说：

- “Agent 会自动学习并上线更好的策略”。
- “生成建议就证明旧参数不好”。
- “Replay Badcase 能证明真实用户效果”。
- “审核通过后系统会跳过离线和线上门禁”。
