# P0 评测真实性改造验收

验收日期：2026-09-14

## 结论

评测工作台现已区分两种完全不同的运行方式：

- 合成回放：读取测试集预置输出，用于验证评测平台、指标计算和 Badcase 闭环；不调用模型、工具或 RAG。
- 本地 Agent 实测：通过 Local Adapter 调用进程内 `UnifiedAgent`；测试输入仍为合成、脱敏数据，执行结果由当前 Agent 在运行时生成。

页面不再把回放的 100% 通过率表述为 Agent 的真实效果，并会显示本地实测所用模型是 Real 还是 Mock、RAG 与外部依赖是否可用。

## 自动化验收

- 评测真实性专项：`python -m pytest tests/test_evaluation_adapter_inputs.py tests/test_evaluation_evaluators.py tests/test_evaluation_service.py -q`
- Python 全量回归：`python -m pytest tests -q`
- Vue 生产构建：在 `web/` 执行 `npm run build`
- Replay 契约：`execution_mode=synthetic_replay`、`synthetic_execution=true`、`invokes_model/tools/rag=false`。
- Local 契约：`adapter.type=local`、`execution_mode=local_agent`、`synthetic_inputs=true`、`synthetic_execution=false`。

本验收文档不固化会随用例增长而过期的通过数；最终证据必须保留同一提交、同一命令的实际输出与跳过项。

## 本地 Agent 冒烟实测

在无外部模型 Key、无 Milvus/Elasticsearch/PostgreSQL/Kafka 的降级环境中，使用项目自己的 `UnifiedAgent` 跑完 `agent_framework_capability_eval.jsonl`：

- 运行状态：completed。
- 用例：19 / 19 完成。
- 执行错误：0。
- 模型口径：Mock。
- 适配器：`agi-saber-local`，不是 Replay。
- 通过率：0%。
- 平均分：0.244408。
- P95 延迟：17622.38 ms。
- 发布门禁：未通过。

这个结果不能包装成“Agent 效果很好”。它说明评测链路已经能测到真实问题：当前通用 Agent 的意图分类、工具参数、RAG 证据和降级恢复能力尚未达到测试集要求。
